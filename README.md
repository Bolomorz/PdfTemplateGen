pdf template generator based on c#-framework pdf-sharp

> make your own dynamic templates using PdfTemplateGen-project using your own objects to dynamically insert data into the template and the resulting pdf-file.

included projects:
- PdfTemplateGen: pdf template generator
- PdfTemplateGenExample: example template depicting an exam overview (grade-table, grade distribution as bar graph and as table)
- PdfTemplateGenBlueprints: blueprints for commonly used structures like tables, certain graphs etc.
